# 圖的搜尋：BFS 與 DFS

分類：演算法｜預估閱讀時間：12 分鐘

狀態：已實作；成品：lessons/graph-search/index.html

## 學習目標

  觀察廣度優先搜尋與深度優先搜尋的走訪差異。  理解 BFS 的佇列和 DFS 的遞迴／堆疊概念。  

## 概念說明

 廣度優先搜尋（Breadth-First Search，BFS）使用先進先出的佇列（queue），先訪問距離起點較近的節點。深度優先搜尋（Depth-First Search，DFS）使用遞迴或堆疊（stack），先沿一條路往深處走，再回頭。  兩者都需要記錄已發現或已訪問的節點，以免在有環的圖中無限重複。  本例為無向圖，起點固定 A，鄰居按英文字母排序。畫面顯示「拜訪順序」，不是走過的連續路徑，也不是內部佇列。 

## 操作範例

 邊集合：A–B、A–C、B–D、B–E、C–F。  BFS：先 A，再同層 B、C，接著 D、E、F，得到  A → B → C → D → E → F 。  DFS：A 到 B 到 D，回到 B 再 E，之後回到 A 走 C 到 F，得到  A → B → D → E → C → F 。

## 常見錯誤

  認為所有圖的 DFS 順序都唯一：鄰居處理順序不同，走訪順序可能不同。  認為 DFS 一定找出最短路徑：一般情況不成立；BFS 的最少邊數保證適用於無權圖。  把拜訪清單當作相鄰路徑：例如 D 與 E 之間沒有直接邊，DFS 需要回溯。  

## 重點整理

  BFS 逐層探索，核心資料結構是佇列。  DFS 先深入再回溯，可使用遞迴或堆疊。  走訪順序受起點、圖結構與鄰居排序影響。
